# 六个带自检的练习

这里顶层的六个 `.c` **故意保留 TODO**。它们可以安全编译，但初次运行应打印 `FAIL` 并返回非零退出码。这是练习的正常起点，不代表编译器或安装出了问题。

只修改 TODO 函数，不删测试、不把 `main` 改成直接返回 0。每题修改后重新编译运行，直到出现 `PASS` 且退出码为 0。测试使用显式条件与返回码，不依赖 `assert`，因此定义 `NDEBUG` 也不会跳过测试。

`solutions/` 中是六份独立、完整的参考答案，文件名与练习一一对应。先自己写，再比较代码；参考答案正常运行均应通过自检。

例如从项目根目录，在 PowerShell 里：

```powershell
New-Item -ItemType Directory -Force build | Out-Null
gcc -std=c17 -Wall -Wextra -Wpedantic -Wconversion -Wshadow .\exercises\01_temperature.c -o .\build\exercise01.exe
.\build\exercise01.exe
$LASTEXITCODE
```

查看参考答案的结果时，单独编译 `exercises/solutions/01_temperature.c`。不能把练习与答案同时链接，因为两者都定义了 `main`。

| 练习 | 对应实验 | 实现目标 | 关键测试 |
| --- | --- | --- | --- |
| `01_temperature.c` | 01–03 | 摄氏转华氏 | 0、100、-40 度，浮点近似比较 |
| `02_array_stats.c` | 04–06、10、15 | 数组总和、最小值、最大值 | 混合正负数、单元素、空输入、空输出指针 |
| `03_string_copy.c` | 06–08 | 有容量限制的完整字符串复制 | 恰好放下、容量不足、空字符串、空指针 |
| `04_pointer_swap.c` | 05、08 | 通过指针交换两个整数 | 普通交换、同一指针、空指针 |
| `05_dynamic_array.c` | 08–09、13 | 自动扩容的整数数组 | 连续追加 20 个值、保留旧数据、清理与重复清理 |
| `06_record_lookup.c` | 06、08、10、14 | 按 ID 查找结构体 | 首个重复 ID、中间、末尾、未找到、空数组 |

02 题可先完成基本统计，学到结构体与错误处理后再补完参数及溢出检查。05 题的动态数组也会直接帮助理解主项目的容器设计。

## 01 — 温度转换

函数：`celsius_to_fahrenheit`。公式为 `F = C × 9 / 5 + 32`。

提示：注意 `9 / 5` 单独用整数计算会得到 1。让计算从一开始就使用浮点数。自检通过后，给测试增加 37 摄氏度与 -273.15 摄氏度。

参考答案通过时输出：`PASS: temperature`。

## 02 — 数组统计

函数：`array_stats`。只有成功时才更新 `*result`；空数组没有最大、最小值，直接报告失败。

提示：不能把最小值初始化为 0，否则全正数组会出错。先检查指针与长度，再用首元素初始化最小值和最大值。把结果先放在局部结构体，最后一次性提交。累加前分别检查正数和负数是否会使当前和超出 `long long` 范围。

约定：调用者保证输入数组实际拥有 `count` 个有效元素。实现可以拒绝任何一次中间累加超出范围的输入；不尝试用更大整数表示临时结果。

增加测试：全正数组、全负数组、多个零。最小标准保证的 `long long` 已非常大，小型 `int` 测试数组通常无法触发溢出；这条路径也需要通过代码推导检查，现有自检不宣称覆盖全部输入。

参考答案通过时输出：`PASS: array statistics`。

## 03 — 字符串复制

函数：`copy_text`。容量包含结尾 `\0` 的位置；不足时不能留下半个字符串，也不能改变原缓冲区。

提示：先检查指针及容量，再求 `strlen(source)`。判断 `length >= capacity`，而不是只判断 `length > capacity`。检查完成后，可以用循环或 `memcpy` 复制 `length + 1` 个字节。

约定：源必须是有效的、以 `\0` 结束的字符串，源与目标不重叠；此题不实现重叠复制。自检使用固定长度比较，初始 TODO 没有终止符时也不会越界读。

参考答案通过时输出：`PASS: string copy`。

## 04 — 指针交换

函数：`swap_int`。先检查两个指针，再读取或写入指向的对象。

提示：用一个临时整数保存原值。不要使用 XOR 交换；两个指针相同也必须保留原值。这里交换的是被指向的整数，不是函数中两个局部指针变量。

参考答案通过时输出：`PASS: pointer swap`。

## 05 — 动态数组

函数：`vector_push`。`size` 表示已存在的元素数，`capacity` 表示已分配的槽数；始终保持 `size <= capacity`。

提示：首次分配 4 个槽位，满了就翻倍。分别检查容量翻倍溢出与 `capacity * sizeof(int)` 溢出。`realloc` 要先保存在临时指针中；分配成功后才提交新指针和容量，再写入新元素并递增 `size`。

所有权：一个 `IntVector` 独占它的 `data`。不要简单复制结构体后让两份各自 `free`。`vector_destroy` 已写好，把对象重置成空状态，便于安全复用。

约定：传入的非空对象已经初始化并保持上述不变量。此题不要求把任意伪造指针变成有效对象；也不通过申请巨量内存来模拟失败。内存不足和溢出路径需要阅读实现并推导。

参考答案通过时输出：`PASS: dynamic array`。

## 06 — 结构体查找

函数：`find_task`。从前向后查找，命中后返回该元素的地址；不要返回局部变量的地址。

提示：用 `< count` 遍历，比较 `tasks[i].id`，返回 `&tasks[i]`。先检查空指针。重复 ID 时返回第一个，未找到返回 `NULL`。

生命周期：返回值借用原数组中的对象，不拥有内存，不能 `free`；数组失效后也不能继续使用结果。`const Task *` 表示调用者不能通过这个返回值修改记录。

拓展：把返回值作为只读查询，再实现一个明确允许修改的版本；或者先按 ID 排序，再用二分查找。要说明排序会改变记录顺序，以及如何处理重复 ID。

参考答案通过时输出：`PASS: record lookup`。
