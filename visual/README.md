# C 语言任务工坊 · 可视化学习

在主项目目录双击 **Open-Visual.cmd**，或用浏览器打开 **dist/index.html**。离线版无需安装 Node、网页服务器或第三方依赖；不要只复制 HTML，需保留整个 dist 文件夹。

## 你可以怎样学

1. **学习总览**：按六个阶段进入 22 章中文课程。
2. **章节课程**：阅读讲解与高亮代码，回答本章自测，答对后标记完成；可以收藏章节。
3. **可视化实验**：逐步执行指针示意，操作动态数组观察扩容与借用指针失效，切换位标志，查看 UTF-8 字节和结尾 NUL。
4. **项目实战**：通过界面增删任务、切换完成/紧急、排序、筛选，同时观察 TaskList 的 len/cap/next_id 及对应的 C 函数调用。
5. **动手练习**：编辑六份 TODO 草稿，下载 .c 文件，对照参考答案；在原 C 源码项目中编译并自检。
6. **源码与工具**：阅读七个主项目源文件、16 个独立实验，复制或下载代码及完整 C 源码包。

导航支持窄屏折叠菜单；搜索支持中文关键字与 Ctrl/Cmd K。

## 数据与执行范围

学习进度、收藏、练习草稿和模拟任务保存在**当前浏览器、当前站点**的 localStorage。离线文件、本机预览和线上网站的存储相互独立；清理浏览器数据或换浏览器不会保留它们。如果浏览器禁用存储，界面会提示只保留本次会话。

网页的图解和任务管理器是 JavaScript 教学模型，**不编译或运行任意 C 代码**。真实 C 程序仍由项目中的构建脚本编译。图中的地址是示意地址；扩容可以原地也可以迁移，旧借用指针在成功 realloc 后均须重新获取。

实战演示导出的 tasks.tsv 使用同一 CTASK 文本格式。用原生程序 `build/c-task-lab.exe --file tasks.tsv` 启动后，选择菜单 **8** 读取。网页演示最多 1000 项任务，并将 ID 限制在 Windows unsigned long 可用范围内。

## 文件

- dist/index.html：页面骨架。
- dist/styles.css：响应式界面样式。
- dist/app.js：导航、Markdown 阅读、自测、进度、练习编辑和任务模拟。
- dist/data.js：打包的课程与 C 源码，无需联网请求。
- dist/labs.js / labs.css：四个互动实验。
- dist/downloads/c-task-lab.zip：原生 C 学习源码包。

本地版可以直接打开。开发时也可用任意静态 HTTP 服务器服务 dist。站点为纯静态页面，没有后端编译服务，也不向服务器上传草稿或任务。
