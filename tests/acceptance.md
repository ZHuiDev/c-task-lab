# 交互验收清单

自动核心测试之外，用完整应用确认用户能完成一次真实操作。请在项目目录操作；保存测试会覆盖选定的数据文件。

1. 运行 `build/c-task-lab.exe --file practice.tsv`（Unix 去掉 `.exe`）。
2. 输入 `hello`、`-1`，应提示合法菜单范围并继续等待。
3. 选 2，添加标题“学习 C”、优先级 3；再添加“画内存图”、优先级 1。
4. 选 3 输入 ID 1，选 5 输入 ID 2。选 1 应显示一项完成，第二项有 `!`。
5. 选 6 排序，优先级 3 在前；选 7 保存。
6. 删除任务 2，再选 8 读取。输入 `YES` 后任务 2 应恢复。
7. 退出，重新运行并选 8 读取。两条任务和标志都应保留。
8. 添加第三条任务，编号应为 3。删除它并保存；退出再读入，下一条任务编号应为 4。
9. 退出后用编辑器把文件优先级改为 9。再次运行，先新增一条任务，再选 8、输入 `YES`；应报告格式错误，刚新增的任务仍在内存中。
10. 输入超过 200 字节的一行，再输入合法菜单；长行应丢弃，下一次菜单读取正常。

读取成功会替换当前列表；读取失败保留当前列表。保存直接覆盖指定路径。练习完成后可以自行删除 `practice.tsv`。
